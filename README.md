A Python-based system to manage products, sales, and transactions.  
Supports **admin** and **guest** roles with different access privileges.  

**Features:**
- Add and display products (Admin & Guest)
- Make sales (Admin & Guest)
- View transaction summary (Admin)
- View personal sales receipts (Guest)
- Change password (Admin & Guest)

Data is stored locally using JSON files (User data, Product data, Transaction data).
